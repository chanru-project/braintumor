# 🧠 Brain Tumor MRI Classification using Deep Learning

## 📖 Overview
This project is a Deep Learning-based web application that classifies Brain MRI images into four categories: **Glioma**, **Meningioma**, **Pituitary Tumor**, and **Healthy**. Built with **TensorFlow, Keras, and Streamlit**, it enables users to train a CNN model, explore the dataset, and predict tumor types from MRI scans through an interactive interface.

## ✨ Features
- 🧠 Brain MRI Tumor Classification
- 🤖 CNN-Based Deep Learning Model
- 📊 Interactive Data Visualization
- 🖼️ MRI Image Upload & Prediction
- 📈 Training Accuracy & Loss Analysis
- 📉 Confusion Matrix Visualization
- ⚡ User-Friendly Streamlit Dashboard
